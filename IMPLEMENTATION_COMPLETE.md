## 🎯 Quick Start Guide

### 1. Deployment Cepat
```bash
# Clone repository
git clone <repository-url>
cd brankas

# Jalankan deployment otomatis
sudo ./scripts/deploy.sh

# Optimasi konfigurasi
./scripts/configure-optimize.sh --deployment-type banking-grade --optimize-for balanced

# Validasi kesiapan produksi
./scripts/production-readiness-check.sh
```

### 2. Monitoring Real-time
```bash
# Dashboard monitoring interaktif
./scripts/security-monitor.sh dashboard

# Monitoring background
./scripts/security-monitor.sh monitor

# Generate security report
./scripts/security-monitor.sh report
```

### 3. Testing dan Validasi
```bash
# Jalankan test suite lengkap
cargo test --release

# Benchmark performa
cargo bench

# Load testing
./scripts/load-test.sh
```
